# Log Analyzer (C + Python)

Инструмент для высокопроизводительного парсинга серверных логов и генерации визуальных HTML-отчётов. Проект сочетает скорость языка **C** при построчной обработке файлов с гибкостью **Python** для аналитики и построения графиков.

## Архитектура проекта

Конвейер разделён на два независимых этапа, связанных через JSON-контракт (`results/results.json`):

1. **C-ядро (`c_engine/main.c`):**
   - Построчное чтение лог-файлов (`fgets` + `sscanf`) с защитой от переполнения буфера.
   - Подсчёт событий по уровням (`INFO`, `WARNING`, `ERROR`, `UNKNOWN`).
   - Группировка уникальных ошибок и поминутной активности с использованием динамической памяти (`realloc` / `free`).
   - Сортировка ошибок по частоте и экспорт результатов в `results/results.json`.
2. **Python-модуль (`python/`):**
   - `analyzer.py` — валидация JSON-схемы, расчёт процентного соотношения уровней и поиск пиковой минуты сбоев.
   - `vizualization.py` — генерация диаграмм распределения уровней и таймлайна ошибок через **Matplotlib**.
   - `report.py` — сборка автономного отчёта `results/report.html` в тёмной теме.
